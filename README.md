# SellerMetric

Production-ready Flipkart seller analytics application using the custom SellerMetric landing page and the complete analyzer from [beingnitishh/SellerMetric](https://github.com/beingnitishh/SellerMetric).

## Features

- Auto-detects Flipkart Sales and Return reports
- CSV, XLSX, XLS, and TSV parsing in the browser
- Sales KPIs, charts, SKU/category tables, daily trends, leakage analysis, and advanced insights
- Return KPIs, RTO/customer-return analysis, refund leakage, filters, charts, reason analysis, and SKU drill-down
- No server upload or account required
- Responsive custom SellerMetric landing page

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The Vite output is generated in `dist/`. The project is ready for Vercel static deployment.
